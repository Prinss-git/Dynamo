# Dynamo - Student Organization Event Registration and Attendance System

ASP.NET Core MVC with Razor views (C#, .NET 9) and SQL Server Express.

The whole system lives in [`ASIBasecodeCsharp/`](ASIBasecodeCsharp/). Open `ASIBasecodeCsharp/ASI.Basecode.sln`
in Visual Studio and follow [`ASIBasecodeCsharp/README.md`](ASIBasecodeCsharp/README.md) for setup, the demo
accounts and deployment.
